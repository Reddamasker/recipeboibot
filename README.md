# Recipeboibot / @Recipeboibot

Закрытый тест личной библиотеки рецептов: Telegram-бот принимает ссылки, текст, изображения и голосовые, сразу сохраняет понятный материал и ищет по личной коллекции; Mini App даёт коллекцию, редактор и режим готовки. AI-обработка реальная, fake-адаптеров в продукте нет. Рабочее название бренда не утверждено.

Развёрнуто: https://recipes.spas-sky.ru, бот https://t.me/Recipeboibot. Для входа нужно открыть бот и нажать Start; пароль и код приглашения не используются. Обычный браузер не даёт доступ к личной библиотеке: API проверяет Telegram `initData`, данные изолированы по Telegram-пользователю.

## Что работает

- голосовой и текстовый запрос из обычного чата: ASR → определение намерения → результаты из личной коллекции без обязательного подтверждения расшифровки;
- автоматическое сохранение текста, фото и ссылок из чата без второго Save; повтор и параллельная доставка дедуплицируются;
- импорт текста и фото через `gpt-5.6-luna`;
- импорт URL: Schema.org Recipe → текст страницы → AI-нормализация;
- YouTube: отдельное извлечение описания и доступных субтитров, включая короткие ссылки и Shorts; если текста нет — понятная ошибка без выдуманного рецепта;
- Instagram/TikTok/VK Video: загрузка публичного ролика, описание автора и автоматическая расшифровка звука; приватные и требующие входа ролики не обходятся;
- голос через `gpt-4o-mini-transcribe`;
- ручное редактирование, личная SQLite-библиотека, локальный поиск и режим готовки;
- source previews для YouTube и доступных Open Graph-изображений; без AI-фотографий;
- прямые ссылки Telegram на рецепт и сетку результатов Mini App;
- ручное право на добавление бота максимум в три группы: поиск и сохранение работают с коллекцией владельца группы, без права бот объясняет отказ и выходит;
- проверка Telegram `initData`, tenant isolation, SSRF-защита, лимиты размера и AI-запросов.

## Локальный запуск

Требуется Node.js 24+. Внешних npm-зависимостей нет.

```powershell
Copy-Item .env.example .env.local
# Заполнить секреты
node --test --test-concurrency=1
node src/index.js
```

Проверка: <http://127.0.0.1:3087/healthz>. Mini App не имеет dev-bypass: полный UI открывается только в Telegram после HTTPS-деплоя.

Реальная проверка AI:

```powershell
node scripts/smoke-openai.js
```

Ручное управление правом на группы выполняется по неизменяемому Telegram ID:

```powershell
npm run group-access -- 6971956699 on
npm run group-access -- 193553580 off
```

## Вход в закрытый тест

`node scripts/invite-link.js` печатает обычную ссылку Start без секретного параметра. Ограничение теста организационное; техническая защита личных данных основана на Telegram `initData` и tenant isolation.

## Docker / сервер

```bash
docker compose build
docker compose up -d
docker compose ps
curl -fsS http://127.0.0.1:3087/healthz
```

Проект установлен в `/opt/recipeboibot` на `nikita@72.56.97.79`. `compose.yaml` публикует порт только на loopback, ограничивает память/CPU и ротирует логи. Nginx: `deploy/recipeboibot.conf`, сертификат `/etc/letsencrypt/live/recipeboibot`. Существующие сайты не изменялись. Пользователь разрешил мягкий reload после успешного `nginx -t`; он выполнен. Для обновления приложения достаточно `docker compose up -d --build`, reload nginx не требуется.

Резервная копия: `sudo sh deploy/backup.sh /opt/recipeboibot/backups`. Таймер `recipeboibot-backup.timer` запускает её ежедневно в 04:15 по часовому поясу сервера с задержкой до 5 минут. Копии зашифрованы AES-256-CBC/PBKDF2; ключ `backups/backup.key` нельзя потерять. Копию ключа и архивов нужно отдельно хранить вне сервера: сейчас offsite-копии не настроены. Автоматической ротации нет; следить за диском. Сертификат обновляет certbot, проектный deploy-hook выполняет проверку и мягкий reload nginx.

Требования к порогам нагрузки и незавершённая задача `MON-001` по мониторингу зафиксированы в [docs/LOAD_MONITORING.md](docs/LOAD_MONITORING.md). До её выполнения автоматических оповещений о CPU, памяти, диске, очереди импорта и блокировках SQLite нет.

## Тесты

```powershell
node --test --test-concurrency=1
```

54 теста проходят: Telegram auth/expiry, tenant isolation, Start нового и возвращающегося пользователя, доступ и лимит групп, выход при отказе права, страница группового доступа, intent/ASR route, поиск с учётом формы слов, согласие перед генерацией при пустом поиске и отдельное подтверждение сохранения, source-level дедупликация/повтор/параллельность, восстановление job/update после сбоя, ручные правки, SSRF, дневная/общая квоты, deep links, мобильная сетка, YouTube URL/JSON/subtitle-парсер, ссылки Instagram/TikTok/VK Video и недоступные источники.

Реальными API проверены текстовый импорт, изображение с рецептом, URL BBC Good Food и ASR: синтезированная русская фраза «Есть курица, что приготовить на ужин?» распознана дословно через `gpt-4o-mini-transcribe`. Живое голосовое из Telegram не отправлялось, чтобы не писать пользователю и не загрязнять рабочие данные. В изолированном UI-стенде пройдены главная, поиск, двухколоночные результаты, прямое открытие рецепта, возврат с сохранённым запросом, редактор и режим готовки. Получение субтитров ролика `79aqvX4RnEU` повторно проверено внутри рабочего контейнера после деплоя; AI при этой проверке не вызывался. `node scripts/check-youtube.js` проверяет источник без AI; `node scripts/smoke-youtube.js` выполняет один реальный AI-вызов с учётом квоты, без записи в личную библиотеку. Тестовый сервер `scripts/ui-test-server.js` не входит в Docker-образ и не должен публиковаться.

## Ограничения MVP

- Instagram, TikTok и VK Video обрабатываются только по публичной ссылке: сервис временно загружает один ролик размером до 24 МБ, передаёт его в распознавание речи и сразу удаляет временный файл; приватные материалы, аккаунты, cookies и обход ограничений не используются;
- YouTube использует публичный player-интерфейс (подход проверен по исходникам `youtube-transcript-api`); интерфейс может меняться. Аккаунты, cookies, прокси и обход ограничений не используются. Видеокадры не анализируются, автосубтитры могут ошибаться; предупреждение сохраняется в рецепте;
- реальный AI-тест ролика `79aqvX4RnEU` извлёк ингредиенты и шаги. Количества и шкала температур не заданы в субтитрах: такие сведения не должны додумываться. Разные способы приготовления могут быть неоднозначны без просмотра кадров;
- поиск выполняется только по личной SQLite-коллекции; при отсутствии совпадений AI предлагает отдельный рецепт, который добавляется в коллекцию только после подтверждения;
- SQLite подходит для закрытого теста, но не для массового запуска;
- максимум 40 AI-запросов в сутки и 80 за всё время жизни БД; неуспешные попытки тоже учитываются; автоматических повторов нет. Это лимит количества, не гарантия денежного hard cap: точный остаток $10 здесь не проверен;
- Telegram updates обрабатываются последовательно; статусы update/import устойчивы, после прерывания тот же источник можно безопасно отправить повторно без дубля;
- в группах используются команды `/find` и `/save` либо ответ на сообщение бота; при стандартном Privacy Mode Telegram не передаёт боту весь обычный разговор;
- базовые `/privacy.html` и `/terms.html` подготовлены для закрытого теста, не заменяют юридическую проверку перед публичным запуском;
- история версий, экспорт, embeddings и полноценные адаптеры соцсетей не реализованы.
