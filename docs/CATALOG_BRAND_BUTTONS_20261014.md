# Фирменные кнопки Telegram и MAX

14 октября 2026. Только тестовый контур, продолжение ревью экрана приглашения с телефона.

Telegram: оригинальный SVG из официального набора https://telegram.org/tour/screenshots (архив https://telegram.org/file/464001088/1/bI7AJLo7oX4.287931.zip/374fe3b0a59dc60005), сохранён в public/brand/telegram.svg без изменения геометрии и цветов. Синий фон кнопки #087bb5 выбран для контраста белого текста. Это наша ссылка с официальным знаком, не виджет авторизации или отправки сообщений.

MAX: оригинальный белый SVG https://st.max.ru/brandbook/max-white.zip из https://go.max.ru/brandbook, сохранён в public/brand/max-white.svg. Фон из официальной палитры #471AFF, #6E1AFF, #9500FF. Готовые виджеты/кнопки на странице брендбука пока помечены «СКОРО», поэтому использовано собственное оформление ссылки. Внешние скрипты и зависимости не добавлены, логотипы отдаются нашим сервером.

Изменение только визуальное: тексты, переходы, доступы и аналитика прежние. Вход benefits_view, первое нажатие любой платформы benefits_cta, отказ benefits_close, ошибки client_error, надёжность telemetry_health; длительность от видимого показа в существующих событиях. Идемпотентность, скрытые состояния, начало сбора, отчёты дашборда и bridge v7 не меняются. Никаких новых событий или персональных данных. Результат перехода не означает запуск бота.

CSS v11. На 320×568 обе кнопки 137×50, содержимое диалога 320×568 без прокрутки; логотипы загружены. Пустой alt и aria-hidden оставляют доступные названия Telegram и MAX. Сохранены focus-visible и touch targets. 13/13 целевых тестов прошли; новых тестов на цвета не добавляли.
