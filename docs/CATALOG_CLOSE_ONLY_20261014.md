# Удаление нижней кнопки «К рецепту»

14 октября 2026, только тестовый контур. По запросу владельца удалены кнопка benefits-continue, её обработчик и стили. Закрытие крестиком и Escape сохраняет рецепт, позицию прокрутки и возврат фокуса. Внизу остаются только Telegram и MAX, добавлен небольшой отступ до края с учётом safe-area. CSS v12, JS v6 защищают от старых кешированных обработчиков.

Существующие benefits_view → benefits_cta / benefits_close, durationMs, client_error и telemetry_health покрывают сценарий. Закрытие крестиком/Escape продолжает давать benefits_close; убран только один дублирующий способ закрытия. Метрики, схема bridge v7, очередь, идемпотентность и начало сбора не меняются, новые события не нужны. Клиентские тесты обновлены под три оставшихся контрола: последний MAX замыкает фокус на крестик. Удалён тест отсутствующей кнопки; сохранены проверки закрытия, скрытого состояния, повторов, ошибок трекера и возврата фокуса.

Целевые тесты 12/12. Предпросмотр: https://recipeboibot-test.89-223-123-75.sslip.io/recipes/pork-cabbage?benefits=preview . Основной Telegram/MAX не переиздаются.
