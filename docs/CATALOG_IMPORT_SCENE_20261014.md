# Иллюстрация преобразования личных рецептов

14 октября 2026. Продолжение тестового ревью экрана приглашения. По запросу владельца изображение книги в блоке «Готовьте любимое / Свои рецепты — в подборке» заменено схемой преобразования разных источников в структурированный рецепт. Образец смысла — существующий lp-showcase на лендинге public/index.html.

Входы: видео с кнопкой воспроизведения, текстовая заметка, голосовое сообщение. Выход: одна карточка с ингредиентами и последовательными шагами. Фирменная сиренево-ягодная палитра, векторные элементы, без фотографии блюда. SVG остаётся в прежнем месте и размере; подписи, две фирменные кнопки, весь остальной экран и обработчики не меняются. Смысл схемы доступен через role=img и aria-label. Никаких внешних загрузок или новых зависимостей.

Аналитика: исключительно замена иллюстрации. Существующие benefits_view → benefits_cta / benefits_close и durationMs покрывают показ, действие и отказ; client_error и telemetry_health — ошибки/потери. Переход не означает успешный запуск бота. Идемпотентность, скрытые состояния, очередь, реестр, дашборд, начало сбора и bridge v7 остаются прежними; новых событий и данных нет. Поведение реального UI проверено в V5, в этой итерации проверяется визуальное отображение в preview, исключённом из аналитики.

Предпросмотр для телефона: https://recipeboibot-test.89-223-123-75.sslip.io/recipes/pork-cabbage?benefits=preview . Только тестовый контур; основной Telegram/MAX не переиздаются.
