# Иллюстрация преобразования личных рецептов

14 октября 2026. Продолжение тестового ревью экрана приглашения. По запросу владельца изображение книги в блоке «Готовьте любимое / Свои рецепты — в подборке» заменено схемой преобразования разных источников в структурированный рецепт. Входы: видео с кнопкой воспроизведения, текстовая заметка, голосовое сообщение. Выход: одна карточка с ингредиентами и последовательными шагами. Смысл схемы доступен через role=img и aria-label. Никаких внешних загрузок или новых зависимостей.

Поведение реального UI проверено в V5, в этой итерации проверяется визуальное отображение в preview, исключённом из аналитики.
