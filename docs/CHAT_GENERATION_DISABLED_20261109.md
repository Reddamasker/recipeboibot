# Отключение генерации рецептов по запросу в чате

По запросу владельца отключаем ИИ-генерацию рецептов из чата тестового бота. Общий обработчик Telegram/MAX использует `CHAT_RECIPE_GENERATION_ENABLED`: без явного значения генерация выключена только при `TEST_CONTOUR=true`. Основные контуры по умолчанию сохраняют прежнее поведение.

Запросы текстом, обычные голосовые пожелания, `/find`, `/search`, `/dinner`, `/ingredients`, старые кнопки создания/замены/уточнения больше не запускают генерацию. Ответ сообщает об отключении и даёт вход в коллекцию. Фоновый подбор из чатового старта/анкеты тоже отключён. Открытие и сохранение ранее полученного рецепта, импорт готовых рецептов, предпочтения и отдельные API Mini App сохранены.

Публикация ограничена тестовым Telegram. Отдельного тестового MAX в конфигурации проекта нет; основной MAX не включается в выпуск без уточнения владельца. Поддержка переключателя в общем коде проверяется для обоих транспортов. Данные, доступы, квота и настройки окружения не сбрасываются.

Аналитика использует прежние события операции и отказ `403`, без новых счётчиков/полей. Подробные определения — в контракте. Фактический выпуск, проверки и ограничения будут записаны после завершения.
