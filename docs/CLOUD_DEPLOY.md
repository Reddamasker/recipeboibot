# Выпуск ботов из Codex Cloud

Облачная среда `recipeboibot` использует `main` на GitHub. На сервере учётная запись `recipe-deploy` принимает команды проверки и выпуска по отдельному SSH-ключу. Код приложения, каталог, тесты и `package.json` берутся из коммита. Служебные скрипты и Dockerfile берутся из установленной серверной копии. Изменения этих файлов, начальная настройка MAX и настройки платежей выпускаются прежним административным способом.

## Настройка среды

- В настройках среды `recipeboibot` подключи Tailscale. Для облачных задач используется отдельный reusable и ephemeral ключ Tailscale. Его сетевые права ограничиваются соединением с сервером выпуска по TCP 22.
- Добавь переменную среды `RECIPEBOIBOT_CLOUD_DEPLOY_HOST` со значением IPv4 или MagicDNS-имени `recipeboibot-deploy` в Tailscale.
- Добавь требование персональной переменной `RECIPEBOIBOT_CLOUD_DEPLOY_KEY`. В Personal vault сохрани её значение для этой среды как Base64 от файла приватного SSH-ключа OpenSSH. Хранилище HTTPS-секретов для SSH не используется.
- Опубликуй настройки и запусти задачу в обновлённой среде. Клиенту требуются Node.js 24+, Git и OpenSSH.

Рабочие базы, резервные копии и токены остаются на сервере. Для локального запуска приложения в облаке используется `node scripts/preview.js`.

## Проверка и выпуск

```sh
node scripts/deploy-test.js --check
node scripts/deploy.js --check
node scripts/deploy-max.js --check
```

Проверить передачу и подготовку пакета без перезапуска можно через `node scripts/cloud-deploy.js test --validate`. Вместо `test` доступны `production` и `max`. Для обычного выпуска используй штатные команды `--apply` в порядке тестовый → основной → MAX. Для изменений только лендинга действуют правила `AGENTS.md`.

Клиент проверяет ключ сервера, запускает тесты и передаёт содержимое коммита по SSH. Сервер запускает штатный выпуск с резервным копированием, проверкой работоспособности и сверкой `src/public`. Для отзыва доступа администратор удаляет ключ из `/var/lib/recipe-deploy/.ssh/authorized_keys` и из Personal vault.
