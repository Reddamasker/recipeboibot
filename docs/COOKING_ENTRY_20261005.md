# Запуск готовки без повторной карточки

При первом запуске готовки из карточки ещё не выбранного блюда cookFromDinnerDetail подтверждал выбор через acceptDinnerItem. Этот обработчик одновременно запускал асинхронное openRecipe для сохранённой копии. После открытия cookMode поздний ответ openRecipe закрывал режим и вновь показывал карточку. Сценарий воспроизведён с задержанным ответом.

Теперь подтверждение выбора для готовки передаёт openSelectedRecipe=false, а обычный лайк сохраняет прежнее автоматическое открытие карточки. Перед готовкой из любой карточки закрывается исходный overlay; позднее получение фотографии не может восстановить карточку вместо готовки. cookMode также отменяет ожидающие открытия рецепта через revision. Шаги, кнопки навигации, отметка приготовления, оформление, эмодзи и путь преимуществ/trial не переработаны. Клиент dinner-10.72.
