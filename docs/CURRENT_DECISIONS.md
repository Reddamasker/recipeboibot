## Реализация клиентского сценария v2 — 21 сентября 2026 года

- Основной путь перенесён в обычный чат Telegram: текст или голосовое распознаются, ясный поиск сразу выполняется только по личной коллекции, ясное сохранение создаёт рецепт автоматически. Команда и подтверждение расшифровки не нужны.
- При неоднозначной фразе бот задаёт один вопрос «найти или сохранить» и хранит ожидающий выбор в SQLite.
- Start больше не требует пароля или кода. Mini App по-прежнему проверяет подписанный Telegram `initData`; коллекции изолированы по пользователю.
- Импорт получает устойчивый job до AI-вызова. Дедупликация атомарна в границах пользователя по `source_key`; YouTube использует video ID, остальные URL очищаются от tracking. Повтор и параллельная доставка не создают второй рецепт или AI-вызов.
- Сохранение из чата и ручной формы сразу создаёт готовый рецепт; старые успешно извлечённые черновики мигрируют в `ready`. Статусы незавершённых/ошибочных job видны после повторного открытия Mini App.
- Mini App показывает два главных действия «Что приготовить?» и «Мои рецепты», ручное сохранение вторично. Бренд «Ложка» удалён. Экран рецепта функционально сохранён и доступен по прямой ссылке.
- Карточки остаются по две в ряд. Для YouTube используется исходный thumbnail, для доступных веб-страниц — Open Graph preview, иначе честная подпись «Превью недоступно». AI-фото не используются.
- Поиск больше не передаёт библиотеку модели и не предлагает генерацию вместо отсутствующего совпадения. Запрос хранится в URL результатов, прямой рецепт — в параметре `recipe`; возврат восстанавливает список и запрос.
- Telegram update и import job имеют состояния `processing/done/failed`; после прерывания обработку можно безопасно повторить тем же источником.
- Автоматический набор расширен до 30 тестов; локальный browser QA подтвердил главную, поиск, сетку результатов, прямое открытие рецепта и возврат без ошибок консоли.

Активная конфигурация на момент аудита: `OPENAI_TEXT_MODEL=gpt-5.6-luna`, `OPENAI_TRANSCRIBE_MODEL=gpt-4o-mini-transcribe`. Официальная документация OpenAI подтверждает оба model ID. Фраза пользователя «тот API, четвёртый GPT» остаётся неоднозначной: она может означать GPT-4o для ответов либо ранее утверждённую связку. Поэтому платная текстовая модель не переключалась; требуется отдельное точное подтверждение.

Пользователь затем явно подтвердил оставить текстовую модель без изменений.
