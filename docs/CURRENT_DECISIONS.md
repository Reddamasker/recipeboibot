## Реализация клиентского сценария v2 — 21 сентября 2026 года

- Основной путь перенесён в обычный чат Telegram: текст или голосовое распознаются, ясный поиск сразу выполняется только по личной коллекции, ясное сохранение создаёт рецепт автоматически. Команда и подтверждение расшифровки не нужны.
- С 23 сентября 2026 года короткое текстовое или расшифрованное голосовое сообщение без явной цели по умолчанию запускает поиск в коллекции. Подробный текст с признаками рецепта, явная просьба сохранить, ссылка или фото запускают импорт. Длинное сообщение без ясной цели либо сообщение с признаками и поиска, и сохранения по-прежнему вызывает уточнение.
- Start больше не требует пароля или кода. Mini App по-прежнему проверяет подписанный Telegram `initData`; коллекции изолированы по пользователю.

- Сохранение из чата и ручной формы сразу создаёт готовый рецепт; старые успешно извлечённые черновики мигрируют в `ready`. Статусы незавершённых/ошибочных job видны после повторного открытия Mini App.

- Поиск больше не передаёт библиотеку модели и не предлагает генерацию вместо отсутствующего совпадения. Запрос хранится в URL результатов, прямой рецепт — в параметре `recipe`; возврат восстанавливает список и запрос.

- Автоматический набор расширен до 30 тестов; локальный browser QA подтвердил главную, поиск, сетку результатов, прямое открытие рецепта и возврат без ошибок консоли.
