# Ежедневный рецепт из каталога — 9 ноября 2026

Задача владельца: автоматическая смена каждый день, проверки и выпуск только в `@recipeboi_test_bot`. Основной Telegram и MAX не публиковать и не перезапускать.

## Поведение

- `/api/catalog/daily` выбирает карточку из всех 340 публичных рецептов. Поиск, фильтры и пагинация выбора не меняют; личные рецепты в него не входят.
- Один рецепт на московскую календарную дату, смена ровно в 00:00 МСК. Последовательность по стабильным ID проходит каталог без повторов за цикл; при неизменном каталоге повтор через 340 дней. Обновление состава каталога меняет цикл.
- Выбор одинаков для всех пользователей, не зависит от часового пояса телефона, повторного открытия или рестарта сервера. AI, cron, новые данные и расход квоты не нужны.
- API возвращает время сервера и следующей смены, `Cache-Control: no-store`. Открытая вкладка обновляет карточку по сроку и при возвращении из фона; при уходе в другой раздел или поиск авторотация не вмешивается. Задержанный старый ответ не заменяет свежую выдачу. После ошибки виден повтор, автоматическая попытка — через минуту.
- Открыть, сохранить и поделиться используют ID выбранного блюда. Дизайн карточки и палитра сохранены; cache shell `daily-1`.
