# Общий режим воронки — 5 октября 2026

Владелец заметил «Нет данных» при выборе «Все пользователи». Причина: прежнее объединение требовало рекламной статистики у каждого размещения, включая site-landing («Лендинг — прямые посещения»). Его неизвестные показы и отсутствие импорта Директа делали весь итог неизвестным. Блок «Яндекс Директ» при этом показывал только первую кампанию, а обновление общего режима также обновляло только её.

Общий режим теперь суммирует показы, подтверждённые клики и расходы подключённых кампаний Директа; обычные обращения к ссылкам остаются в диагностике и не заменяют рекламные клики. Органика не обнуляет рекламный итог и не добавляется к его кликам. Запуски, рецепты, trial и оплаты в общем режиме сохраняют всех допустимых пользователей, включая органику. Конверсия «Клик → запуск» использует только новые рекламные запуски с привязанным click_token, исключает владельца, служебные профили и повторных пользователей. Одну внешнюю кампанию через разные метки нельзя посчитать дважды: выбирается последний доступный снимок по CampaignId.

В карточках показов/кликов явно указаны кампании Директа. Блок Директа — общий итог со взвешенной ценой клика (сумма расходов / сумма кликов) и временем самого раннего из последних импортов учтённых кампаний. Если первый импорт одной кампании ещё не завершён, показана известная часть с количеством учтённых кампаний; недоступные данные не заменяются нулями. Успешный пустой отчёт считается нулём. Ошибки обновления сохраняют предыдущие числа и отображают состояние ошибки. У отдельного размещения его прежний фильтр и значения сохранены; для органического размещения панель чужой кампании Директа скрыта.

Кнопки обновления в общем режиме запрашивают все три настроенные кампании. Отказ одной не мешает обновлению остальных и сообщается пользователю; автоматический интервал пять минут сохранён. Явный campaign=all сохраняется после входа. dashboard.html отдаётся с Cache-Control: no-store, клиент dashboard.js?v=11; новые изменения не должны застревать в часовом кэше страницы. Неизвестный уникальный охват и доли с нулевым знаменателем по-прежнему остаются неизвестными — это отдельные корректные случаи.
