# Исправление сравнения с Директом — 5 октября 2026

На снимках владельца Директ показывал 34 показа, 2 клика и 5,45 ₽ расходов, а дашборд — 30 показов, 100 «переходов» и один запуск/рецепт/trial. Причины подтверждены: последний импорт был в 07:50:11 МСК, обновление раз в час; верхняя карточка считала обращения к редиректу, включая повторные и проверки; режим «Все пользователи» включал органического пользователя. Реальная БД содержала 30/2/545 копеек, а кабинет уже 34/2. Расход API с НДС совпадал с мобильным Директом; веб-кабинет отображал 4,46 ₽ без НДС.

Теперь подключённая реклама использует клики Директа в карточке и конверсиях. Обращения к ссылке сохранены отдельно в диагностике и таблице меток, с точной подписью. При неизвестном числе рекламных кликов остаётся «Нет данных»; обращения другого размещения не подменяют недостающие рекламные клики в общей сумме. Общий режим не рассчитывает рекламную конверсию в запуск, поскольку включает органику.

При открытии /dashboard без выбранного фильтра по умолчанию открывается ya-dinner-202610; явный выбор «Все пользователи» или другого размещения сохраняется в URL. Время данных бота и последнего импорта Директа подписаны отдельно. Автоимпорт каждые 5 минут, открытая страница перечитывает сохранённые данные раз в минуту; обе кнопки обновления запрашивают новый отчёт Директа. Каждый импорт получает новое имя отчёта, при ответах 201/202 повторяется тот же запрос. Ошибки сохраняют последние успешные данные. Реальный импорт в тестовом и preview по-прежнему отключён. Статистика самой площадки может уточняться; одновременного совпадения в реальном времени не обещаем.

Проверки: 398/398 локальных, включая HTTP-проверку авторизованного дашборда на сценарии 100 обращений / 2 клика / 34 показа, отделение органики, расчёт конверсий, неизвестные клики и сохранение данных при отказе API. Изолированное браузерное демо с отдельной БД, без polling/AI. Публикация и проверка рабочих контуров выполняются.

Источник о возможном уточнении статистики: [документация Яндекса](https://yandex.ru/dev/direct/doc/ru/actual).
