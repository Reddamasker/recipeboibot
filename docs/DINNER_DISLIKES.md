# Замена одной карточки в подборке

Запрос владельца от 2 октября 2026: в подборке из трёх рецептов нажатие на карточку открывает полный рецепт. Отдельная кнопка дизлайка «Не подходит» раскрывает рядом с этой карточкой три причины:

- «Не хочу сегодня» — отказ в текущей сессии.
- «Такое не люблю» — название блюда учитывается в следующих подборках; сигнал хранится независимо от срока истории последних показов.
- «Нет ингредиентов» — отказ в текущей сессии без дополнительного обязательного вопроса. Отсутствующие конкретные продукты не угадываются и не превращаются в аллергию или постоянное исключение.

Выбор причины отправляет POST /api/dinner/recommendations/:id/replace. Сервер берёт подходящий готовый вариант из резерва, предпочитая ту же роль в подборке. Отказ, причина и показ замены записываются одной транзакцией. Аддитивная колонка dinner_options.display_position сохраняет позицию; две соседние карточки остаются прежними, в том числе в сессиях старой версии.

Повтор запроса после потери ответа не отклоняет ещё один рецепт. Нельзя заменить чужую, устаревшую карточку или карточку после выбора ужина; требуется активный доступ. При отсутствии подходящего готового резерва сервер возвращает понятный отказ, оставляя исходную карточку. Запрос не сбрасывает профиль, продукты, историю, сроки доступа или AI-квоту. Обычное фоновое пополнение резерва использует прежний механизм.

Общая кнопка замены всей тройки и отдельный экран шести причин убраны из интерфейса. Старые API пакетной замены и причин сохранены для совместимости с открытыми клиентами. Первый бесплатный рецепт и отдельный диалог запроса рецепта не меняются.

Проверки: замена всех трёх позиций/причин, повтор HTTP, повторное открытие, старые сессии без позиции, сохранение профиля и продуктов, отсутствие резерва, чужой аккаунт, доступ и выбранный ужин. UI-проверки: точные три причины, отдельные действия карточки и дизлайка, блокировка повторных нажатий, восстановление при сетевой ошибке. Браузер: полный рецепт открывается; при замене средней карточки соседние сохраняются; ширины 390 и 320 px без горизонтального переполнения.

## Выпуск

Статус публикации и резервные копии будут записаны после проверки серверов. Эксперимент оплаты, ранее опубликованный только в тестовом боте, не входит в основной выпуск.
