# Ожидание замены рецепта — 6 октября 2026

В основном боте в 12:34:23 и 12:34:25 МСК замена возвращала 422 до завершения фоновой генерации. Это не дневной лимит: replaceDinner проверял готовый запас синхронно.

Замена теперь ожидает текущую генерацию; если она только дополнила видимые карточки, ожидает подготовку резерва. Готовый резерв используется сразу. До успешной замены исходная карточка сохраняется. После ожидания повторно проверяются доступ, актуальность пожелания и выбранный ужин; повторные запросы возвращают актуальные карточки без второго отказа. Интерфейс показывает «Готовлю замену…», версия клиента dinner-10.76.

Регрессия с задержанной генерацией проверяет ожидание, общий запрос генерации для повторов, сохранение исходной карточки до ответа и двух остальных карточек после замены. Отдельные проверки сохраняют поведение настоящего исчерпания запаса и ограничения доступа. Проверки выполняются на временных БД без реальных AI-вызовов.
