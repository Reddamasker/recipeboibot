# Расширенный подбор — 13 ноября 2026

## Поведение

«Подобрать» сохраняет поиск, быстрые запросы и рецепт дня. Шесть цветных плиток открывают доступные фильтры: продукты, тип блюда, питание, кухня, повод, способ приготовления. В окне есть поиск, черновой множественный выбор, сброс и применение; закрытие не меняет выдачу. Условия видны на плитках, общий сброс возвращает рецепт дня. Добавлены число результатов и страницы выдачи.

Продукты и ограничения питания объединяются через И, варианты типа блюда/кухни/повода/способа — через ИЛИ внутри группы, сами группы через И. Поиск сочетается с фильтрами. Быстрый запрос начинает новую подборку. Молоко, сыр и творог при включении больше не совпадают по общей группе исключений.

Приоритет РФ: гречка, картофель, творог, капуста, свёкла; русская, домашняя, грузинская, узбекская и соседние кухни; постные блюда, сковорода, духовка, кастрюля, мангал. Фильтры работают по существующему каталогу, без AI-вызовов. Недоступные варианты отмечены «Рецептов пока нет» (сейчас мультиварка). Питание определяется составом рецепта, не является обещанием отсутствия следов аллергенов. Поводы — ориентиры по времени, типу и порциям, а не отдельная экспертная оценка.

## Аналитика

Повторно используем ограниченный реестр: вход и окно фильтра — `screen_view(other)`, применение/поиск/страница/сброс — `step_submit(other)`, подбор — `request_started` с UUID. Видимая непустая выдача — `request_visible(presentation=selection)` с временем до фактической видимости. Пустая выдача — `screen_view(other, results=0)` с UUID попытки; она не считается полным рецептом или успешной подборкой в latency. Сетевая ошибка — `client_error(network)`, серверные статусы — прежние `operation_finished`. Закрытие фильтра без применения остаётся локальным действием без фиктивного запроса.

В дашборде уточнена подпись «Подборка / карточки выбора». Новых агрегатов, схем MAX, персональных полей или границ прежнего сбора нет. Значения продуктов/диет/поиска из Mini App в продуктовую аналитику не передаются. Очередь, ID повторов, фильтры источника и внутренних аккаунтов прежние; анонимный каталог отдельно. Автоматический рецепт дня не создаёт request-событий. Полная карточка и сохранение используют прежние события карточки и workspace.
