## Постоянное размещение

Требование владельца от 27 сентября: production-приложение, единственный Telegram polling, основная база, журналы с пользовательскими данными и резервные копии должны находиться на российском сервере Timeweb `89.223.123.75`. Активная база и резервирование уже перенесены; исторические копии и журналы на старом сервере ещё требуют очистки. Новый зарубежный production-сервер не покупать.

Уточнённая владельцем целевая схема: Telegram → приложение, единственный polling и база на российском Timeweb → транзитный узел в Нидерландах → OpenAI API. На транзитном узле не должно быть базы, пользовательских логов и резервных копий. Для минимизации доступа к содержимому запросов нужен TCP-туннель или HTTP CONNECT с TLS от российского приложения до OpenAI: тогда промежуточный узел видит адрес назначения и сетевые метаданные, но не расшифровывает тело запроса. OpenAI всё равно получает переданные материалы за пределами России. Для Telegram API российское приложение может использовать отдельный маршрут через тот же узел, только если прямое соединение нестабильно; второго polling там быть не должно. Трансграничную передачу пользовательских данных нужно оценить отдельно.

OpenAI API с российского IP отвечает `403 unsupported_country_region_territory`. Транзитный туннель с нидерландским исходящим IP развёрнут по прямому указанию владельца, но это не меняет место пользователей и не создаёт правового основания для передачи данных за границу. В документации OpenAI Россия отсутствует в списке поддерживаемых стран, а соглашение ограничивает предоставление доступа за его пределами. Технически работающий запрос не доказывает соблюдение условий сервиса или требований о персональных данных; нужна отдельная правовая оценка.
