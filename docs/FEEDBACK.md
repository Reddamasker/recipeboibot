# Обратная связь — 2 октября 2026

Ссылка «Обратная связь» доступна в приложении и профиле, кнопка — в главном меню Telegram. На публичном сайте ссылка открывает чат бота с `start=feedback`. Прямая ссылка основного бота: https://t.me/Recipeboibot?start=feedback; тестового: https://t.me/recipeboi_test_bot?start=feedback. Команда `/feedback` принимает одно текстовое сообщение; `/cancel` возвращает предыдущее действие. Форма Mini App: `/?view=feedback`.

Владелец получает текст, имя, username при наличии и ссылку на Telegram-профиль отправителя. Адресат по умолчанию — подтверждённый Telegram ID владельца из существующих документов проекта, `6971956699`; при необходимости его можно переопределить серверной переменной `FEEDBACK_CHAT_ID`. Основной и тестовый бот доставляют в этот личный Telegram; тестовый помечает контур в заголовке.

Обращения до 3000 символов сохраняются в аддитивной таблице `feedback_messages` до отправки. Повтор одного запроса не создаёт второе сообщение. Если Telegram временно недоступен, пользователь видит подтверждение сохранения, доставка автоматически повторяется с задержкой от минуты до часа. Очередь переживает рестарт. Для защиты от спама — до пяти новых обращений за десять минут на Telegram-аккаунт. Содержание не записывается в журналы ошибок. При удалении аккаунта его обращения удаляются из БД каскадно; уже доставленные Telegram-сообщения остаются в переписке владельца.

Mini App использует существующую Telegram-аутентификацию. Подписка не требуется; отправитель и адресат не берутся из полей формы. При использовании отдельного private_test_profile отправитель определяется исходной проверенной Telegram-личностью. Голос, AI и пользовательская квота для обратной связи не используются. Предыдущие анкета, сохранение или запрос восстанавливаются после отправки/отмены, включая отправку формы после команды в чате.
