# Триал после результата подбора — 7 октября 2026

Владелец заметил 4 запуска триала в верхних карточках и 2 в последовательной воронке. Проверка рабочих баз без изменений данных подтвердила результат до триала у всех четырёх: один Telegram-пользователь запросил конкретное блюдо, один MAX-пользователь открыл подборку и начал триал без события принятия варианта. Обязательный этап принятия блюда ошибочно исключал эти пути.

Основная цепочка теперь: запуск → результат подбора → триал → подтверждённая оплата. Отдельное принятие варианта не требуется. «Выбрали рецепт» остаётся независимой метрикой явного выбора из предложенных вариантов и дополнительной конверсией подбор → выбор блюда. Просмотр подборки и запрос блюда не выдаются за подтверждённый выбор.

Сохраняются временной порядок, фильтры внутренних аккаунтов, рекламная атрибуция, уникальность пользователей и исключение тестовых платежей. Для необязательной конверсии выбор → триал отдельно считается selectedTrials, чтобы число всех триалов не делилось на меньшую группу выбравших блюдо. MAX-агрегат версии 4 передаёт новый счётчик и проверяет триал относительно результата, а не выбора. Старый агрегат не принимается за актуальный.

История пересчитывается по существующим записям без миграций или изменений пользовательских данных. Проверки воспроизводят запрос конкретного рецепта, просмотр подборки без принятия, триал до результата, триал без успешного результата, повторные события, дальнейшую оплату и объединение Telegram/MAX.
