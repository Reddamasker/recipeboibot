# Отступы ингредиентов в покупках

По просьбе владельца немного увеличены отступы именно строк ингредиентов: слева 15 → 23 px, сверху/снизу 8 → 12 px, минимальная высота 60 → 68 px. Заголовки категорий и положение чекбоксов по горизонтали сохранены. Новая версия CSS `groceries-spacing-1`.

Это изменение оформления; сценарий, события `workspace_view` и `workspace_action/workspace_saved(groceries.setChecked)`, очередь, дашборд, схема MAX и даты сбора остаются прежними. Новые счётчики и тесты, дублирующие CSS, не вводятся.

Локальный Chrome на 320/393/430 px: фактические отступы проверены, длинное название переносится без горизонтального переполнения, область чекбокса 44 px, отметка сохраняется сервером и имеет видимое аналитическое подтверждение. Ошибок страницы/HTTP нет. Публикация ограничена тестовым ботом; результат выпуска будет дополнен после проверки.
