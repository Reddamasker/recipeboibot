## Ограничения и диагностические замечания

- Это эмуляция размеров в Chromium, не проверка физического телефона, Telegram WebView или реального screen reader. Наличие live region проверено в DOM; фактическая речь screen reader не прослушивалась. Синтезированы pointer/keyboard события, а не полный набор touch-жестов.
- Движок Impeccable не запустился: launcher не обнаружил curl.exe. Применена методика из прочитанного audit playbook с контекстом проекта; автоматический отчёт движка или его overlay не заявляются.
- Первый запуск Chrome внутри песочницы завершился из-за недоступного GPU-процесса; изолированный запуск с одобренным повышением разрешений заработал без отключения защиты Chrome.
- Серия быстрых повторных загрузок временно упёрлась в локальный HTTP rate limit. После истечения окна проверки продолжены без изменения лимитера. Это не ошибка авторизации или модалей.
- Две первоначальные проверки скрипта уточнены: скрытая карточка-демо лендинга не должна считаться открытой модалью; старт готовки из выбранного ужина намеренно закрывает карточку, тогда как вложенный сценарий проверяется из обычного открытия рецепта. Изменений продуктового поведения для прохождения теста не делалось.

Полная сертификация WCAG и новый общий дизайн-рейтинг этой проверкой не заявляются. Подтверждена локальная готовность рассмотренных P1/P2 к следующему этапу выпуска.
