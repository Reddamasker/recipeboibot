## Исправление

Старые подборки отключены по умолчанию общим LEGACY_DINNER_NOTIFICATIONS_ENABLED (в отсутствие явного true — false). Рабочие окружения не должны включать этот архивный режим без нового указания владельца. Совместимый код и его тесты сохранены, чтобы читать историю и старые рецепты; прежние расписания сами по себе не включают отправку.

Защищены запуск таймера, постановка в очередь, обработка старых очередей и повторов, непосредственная отправка напоминания и каждой части digest. Отключены автоматическое подключение к digest, его инициализация и восстановление приветствий. API сообщает enabled=false, available=false, nextDueAt=null и отклоняет включение с 410. Старый экран показывает отключение и переход в коллекцию; обновлён также общий bundle нового Mini App. Из приветствия trial убрано предложение настроить напоминания. Отдельное приглашение сохранить свой рецепт этим исправлением не меняется.

Пользовательские настройки, история рассылок, коллекции, подписки, trial и AI-учёт не сбрасываются. Прямой результат явного выбора старого рецепта не блокируется.
