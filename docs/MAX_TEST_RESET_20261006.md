# Повторная проверка онбординга MAX — 6 октября 2026

По запросу владельца добавлена `/test_reset` в MAX по аналогии с тестовым Telegram. Владелец явно выбрал ограничение только своим аккаунтом. В личном чате команда показывает «Да, сбросить» и «Отмена». Подтверждение удаляет только его аккаунт, рецепты, анкету, предпочтения, историю, первый выбор и пробный/оплаченный доступ. Затем `/start` начинает новый онбординг. Общий учёт AI сохраняется. Реальные аккаунты в ходе проверки не сбрасывались.

Доступ включён отдельным `MAX_TEST_RESET_USER_ID` в серверном окружении MAX. По умолчанию команда закрыта; пустое, нечисловое значение и чужой ID не разрешают сброс. TEST_CONTOUR остаётся false, имитация оплаты не включается. Для остальных MAX-пользователей и основного Telegram сброс закрыт; прежний сценарий тестового Telegram сохранён. Подписанные MAX-события проверяют владельца чата и сообщения. После сброса удаляются сохранённые привязки; ответ не создаёт их снова, поэтому старая кнопка не может сбросить новый профиль.
