# Клипы Одноклассников — 23 ноября 2026

По запросу владельца добавлены публичные клипы OK. Уточнённый порядок выпуска: тестовый Telegram, затем непосредственно целевой MAX. Основной Telegram в этот выпуск не включён.

Ссылки `ok.ru/clip?owner_id=…&clip_id=…` и `/clip/owner/clip`, включая www/m, преобразуются в соответствующий публичный VK-клип для загрузчика видео. В сохранённой карточке остаются каноническая ссылка OK и название «Одноклассники» с автором. Описание и расшифровка звука проходят прежний нормализатор рецепта. Общий лимит HTML не увеличен. Лимиты видео 24 МиБ/90 секунд, удаление временных файлов и запрет выдумывать отсутствующий рецепт сохранены. Обычные страницы профиля и ссылки на видео OK без пары owner/clip не объявляются поддержанными клипами; закрытые/удалённые клипы остаются недоступны.

Идентификатор VK owner/clip общий для обеих площадок: разные параметры пересылки, мобильный адрес и VK-ссылка не создают повторный рецепт. Успешные пользовательские записи и прежние неудачные задания не изменяются автоматически. Для старой ошибки 413 потребуется повторная отправка ссылки пользователем.

## Проверки до выпуска

- Восемь целевых проверок: URL-варианты, неподдерживаемые/опасные адреса, сохранение источника, очистка файлов, описание/звук, ошибка → повтор → сохранение без дубля, учёт статуса и длительности для Telegram/MAX.
- Серверная проверка исходного клипа выполнена в отдельной временной БД с кандидатом кода, без polling и отправки сообщений. Получен «Домашний молочный ломтик»: 13 ингредиентов, 7 шагов, 38,55 с; расшифровка и извлечение успешны. Повтор мобильной ссылки вернул тот же рецепт. Временная БД и файлы удалены; данные и квоты настоящего пользователя не менялись. Это проверка загрузки и обработки, не нативного клиента телефона.
- Аналитика использует прежние события и агрегаты, определение обновлено в дашборде и ANALYTICS_CONTRACT. Источники и содержимое не попадают в события; старые показатели не пересчитываются.
