# Единый экран тарифов для всех пользователей — 4 октября 2026

По снимку с активным trial владелец уточнил: новый экран нужен для всех. Прежний выпуск объединял только сообщение об окончании trial с тарифами, а действующий trial оставлял отдельную месячную карточку и промежуточную кнопку «Выбрать тариф».

Теперь первый запуск trial, активный trial, истёкший trial и оплаченный доступ используют общую страницу с тремя сроками, оплатой, промокодом и блоком согласия на автопродление. Убраны прежняя карточка месяца, строка «Затем ...» и промежуточный переход. При активном trial показан точный срок и пояснение, что покупка начнётся после trial; кнопка «Продолжить пробный период» возвращает к рецептам. До первого запуска сохранена кнопка «Попробовать 7 дней бесплатно», запускающая прежнюю анкету только по явному нажатию. Существующее серверное условие оплаты без промокода до первого рецепта/trial сохранено и объяснено отключённой кнопкой. Выбранные срок и промокод больше не сбрасываются при открытии активного trial.
