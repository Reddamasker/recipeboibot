# Публичные видеорецепты в «Подобрать»

23 ноября 2026 года в основном Telegram проверен импорт от 19 ноября. Владелец видел «Рецепт запечённого сибаса как в ресторане», но обработчик общего каталога отбирал только генерации. Поиск по личным коллекциям для исправления не требуется.

## Путь рецепта

Таймер общего каталога проверяет старые и новые сохранения в основном Telegram и MAX. За один проход на платформу обрабатываются до двух разных источников. Учитываются завершённые задания URL-импорта, связанные с готовым рецептом того же владельца и ключом источника. Тестовый бот только получает результат. Поддерживаются распознаваемые постоянные ссылки на отдельные видео. Перед редакторской проверкой нужны подтверждённые публичность и имя автора. Неопределённый доступ проверяется повторно через сутки, техническая ошибка — через час.

Для неизменённого импорта используются название, описание, порции, время, продукты, шаги и теги оригинального извлечения. После редактирования личной карточки обработчик заново извлекает рецепт из публичного видео. Имя автора берётся из метаданных площадки. В очередь и копию для других пользователей не переносятся личные заметки, изображения, оценки, идентификаторы и параметры ссылки. Редактор проверяет полноту и дубли, а подтверждённая атрибуция проходит через снимок каталога до сохранённой копии. Полное открытие и сохранение работают через прежние маршруты приложения.

## Контрольный ролик

YouTube вернул для GtoVhacNZ9s автора oblomoff и признаки доступного, публично перечисленного видео. Позднее при серверной проверке YouTube запросил вход. Для этой карточки публичность повторно подтвердили независимым анонимным запросом к странице YouTube и передали атрибуцию в общую очередь.

Первичный кандидат отклонён как неполный. Для редакционной версии уточнены ориентировочные количества соли и приправ, режим запекания и время с учётом выдержки. Полная проверка точных дублей и редакторская проверка ближайших блюд завершились решением published/corrected. Общая карточка получила название «Сибас, запечённый с лимоном и орегано» и ID community-f36410618fab78838151b4fd. У сохранённой владельцем карточки осталось своё название.

При редакторской проверке обнаружен HTTP 413 на длинном каталоге. Теперь при сокращении списка аналогов учитывается фактическая длина сериализованного запроса. В проверке с 500 названиями, содержащими кавычки, размер запроса составил 9582 символа при лимите 16000. Для ускорения подбора проверка времени готовки выполняется до сравнения текстов, а заполненный запас рецептов больше не ранжируется повторно.

## Проверка зрителя и аналитики

В браузере открыт настоящий интерфейс мини-приложения в локальном предпросмотре шириной 393 пикселя под отдельным аккаунтом. Исходная база коллекции пуста, в каталог передана только опубликованная общая карточка. Проверены пустой результат, поиск «сибас», один результат, открытие, автор и точная ссылка на YouTube, сохранение кнопкой «В подборку», повторный вход и раздел «Все рецепты». Повторное сохранение оставило одну карточку и одно право доступа. Семейный аккаунт проверяет его владелица самостоятельно.

Зарегистрированы step_submit и request_started, screen_view с results=0, request_visible с длительностью, screen_view для recipe, серверное workspace_saved и видимое workspace_action для collections.saveCatalog. Оценки и заметки пользователя не передаются в события. Служебный отчёт редактора сохраняет платформу, состояния и среднее время проверки. Исторические просмотры не восстанавливаются.
