# Повторный /start до первого лайка

На снимке владельца /start после завершённой анкеты отправлял только подсказку открыть постоянное меню. Предыдущее исправление тройки применялось внутри Mini App, но Telegram-вход не учитывал незавершённый первый выбор. Чтение тестового состояния подтвердило onboarding_completed=1, старый first_recipe_results.request_key=dinner:..., ноль recommendation_accepted и отсутствие trial.

Теперь /start после анкеты при доступном первом выборе отправляет «Продолжим выбор ужина» с прямой кнопкой «Открыть варианты ужина». Кнопка доступна сразу; подготовка использует общий подбор. Старый одиночный показ без лайка также продолжает этот путь. После лайка, при активном доступе или использованном trial прежний вход через меню сохраняется. Незавершённая анкета продолжает свои вопросы. Пользовательские данные и AI-квота не сбрасываются; сообщений от имени владельца не отправлялось.

Регрессия воспроизводит два /start с завершённой анкетой и старым одиночным показом: кнопка ведёт в dinner, доступны три блюда, trial не запущен, меню и преждевременный оффер не отправляются. Целевые проверки: 80/80.
