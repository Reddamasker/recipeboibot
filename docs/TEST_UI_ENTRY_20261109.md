# Вход из сообщений в новый тестовый интерфейс

Причина скриншотов владельца: только `configureTelegramMenuButton` подменял URL на `/review/recime-20261109/index.html`. Общий `webAppUrl`, которым пользуются импорт/уведомления/результаты и кнопки рецепта в сообщениях, возвращал корень с прежним UI. «Назад» закрывал старую карточку и показывал старую главную. Проверка предыдущего выпуска охватывала навигацию внутри нового UI, но не этот вход.

Исправление ограничено тестовым Telegram:

- Новые ссылки всех чатовых сценариев используют адрес нового интерфейса, сохраняя параметры рецепта, доступа, поиска и уведомления.
- Ранее отправленные ссылки на `/` и `/index.html` получают тот же HTML без редиректа; query/hash Telegram и адрес рецепта остаются в браузере.
- Старый `view=menu` внутри нового UI заменяется на `view=collection` с сохранением остальных параметров и без добавления шага истории.
- Основной Telegram/MAX, публичный каталог, общие ссылки `/share/…`, права на рецепты и сценарий открытия пробного доступа сохраняются.
- Предпросмотр с `TEST_CONTOUR=true` использует настоящий серверный вход, чтобы тестовый harness больше не скрывал расхождение.

Проверки и фактический выпуск будут дополнены после завершения. Только тестовый бот; разрешение на его перезапуск ранее получено.
