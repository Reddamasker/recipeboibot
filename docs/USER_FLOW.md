# Рецепты — сценарии и схема экранов v1 (архив)

Актуальная версия: [CUSTOMER_JOURNEY_V2.md](CUSTOMER_JOURNEY_V2.md), 21 сентября 2026. Она заменяет приоритеты главной и путь сохранения ниже: два основных действия — «Что приготовить?» и «Мои рецепты»; ручное добавление вторично; источник появляется в коллекции после отправки в бот, без повторного финального сохранения. Название продукта не утверждено. Остальные положения v1 действуют только там, где не противоречат v2.

Дата: 20 сентября 2026.

Статус: основная логика согласована с владельцем; детализация экранов ниже предлагается как основа для дизайна и реализации. Это целевое поведение, а не отчёт о готовности текущего приложения. Документ не изменяет работающий сервис.

## 1. Зафиксированные решения

- Три основных действия: «Сохранить рецепт», «Что приготовить?», «Мои рецепты».
- Бот принимает материалы и сообщает о результате. Mini App — основное место для просмотра, выбора, редактирования и готовки.
- Доступ по ссылке владельца: ссылка → Start → основные действия. Без регистрации, паролей, ручного ввода кодов и ожидания одобрения. Технический параметр приглашения допустим внутри ссылки; пользователь не должен его вводить или понимать. Пересылка ссылки допускается.
- Авторизация через Telegram и изоляция личных библиотек сохраняются.
- Новому пользователю — короткое объяснение пользы. Возвращающемуся — сразу основные действия, без повторного онбординга.
- Повторный источник не создаёт новую карточку и не расходует AI-квоту автоматически.
- Рецепт, редактирование и готовка — отдельные экраны, не цепочка всплывающих окон.
- Платежей, подписок и дополнительных анкет нет.
- Пока проектируем сохранение рецептов, не календарное планирование меню. Последнее — отдельная возможность, не включённая молча в этот сценарий.

## 2. Точки входа

### Новый пользователь

1. Открывает ссылку владельца в Telegram.
2. Нажимает Start, если Telegram предлагает начать переписку.
3. Получает короткое приветствие и три кнопки.
4. Выбирает действие; Mini App открывает соответствующий раздел напрямую.

Текст приветствия:

> Сохраняйте рецепты из ссылок, текста и фото. Находите нужное обычными словами и готовьте по шагам. Ваша коллекция видна только вам.

Кнопки: «Сохранить рецепт», «Что приготовить?», «Мои рецепты».

Если человек сразу прислал источник в чат, считаем это выбором «Сохранить рецепт», не заставляем возвращаться в меню. При первом старте по приглашению повторный Start не сбрасывает профиль и коллекцию.

### Возвращающийся пользователь

- Кнопка меню бота «Открыть приложение» → главный экран Mini App.
- Кнопки действий в приветствии → нужный раздел.
- Сообщение с результатом обработки → конкретный черновик.
- Отправленный источник → сценарий добавления без предварительного открытия Mini App.
- При устаревшей сессии — понятная кнопка повторного открытия из Telegram, не требование ввести пароль или код.

## 3. Карта экранов

| ID | Экран | Содержание и основное действие | Переход |
|---|---|---|---|
| H | Главная | Три большие кнопки; ниже незавершённая задача и недавние рецепты, если есть | A / Q / L / D / P |
| A | Сохранить рецепт | Ссылка, текст или фото; одна кнопка «Обработать» | Проверка повтора → P или существующий рецепт |
| P | Обработка | Источник, понятный статус; можно уйти из экрана | D после успеха; объяснение и восстановление после ошибки |
| D | Проверить рецепт | Полная карточка черновика, источник и предупреждения; «Сохранить в мои рецепты» | R; «Исправить» → E |
| E | Редактирование | Поля рецепта и заметки; «Применить изменения» | Обратно в D или R, откуда пришли |
| L | Мои рецепты | Сохранённые рецепты, поиск и отдельный доступ к черновикам | R или D |
| Q | Что приготовить? | Свободный запрос, необязательные уточнения; «Подобрать» | Результаты в этом же разделе |
| R | Рецепт | Ингредиенты, шаги, источник, заметки; «Начать готовить» | C; «Изменить» → E |
| C | Готовка | Текущий шаг, прогресс и доступ к ингредиентам | Следующий шаг; завершение → R |

ID служат только для обсуждения схемы и не отображаются пользователю.

## 4. Спецификация экранов

### H — Главная

- Вверху три основных действия с постоянными названиями и понятными подписями.
- «Сохранить рецепт»: «Из ссылки, текста или фото».
- «Что приготовить?»: «Подобрать из моей коллекции».
- «Мои рецепты»: «Посмотреть всё сохранённое».
- Первый визит: короткая подсказка «Начните с рецепта, который хотите сохранить». Никакой обязательной экскурсии по нескольким слайдам.
- Если есть незавершённая обработка или черновик — показать её отдельно, но не открывать принудительно вместо выбранного действия.
- Последние рецепты — ниже основных действий, а не вместо них.

### A — Сохранить рецепт

- Один экран с выбором источника: ссылка / текст / фото.
- Для каждого источника — соответствующий ввод, без дополнительных технических полей.
- Пояснение: «Можно также переслать рецепт прямо в чат бота».
- Перед первой обработкой — короткое сообщение об AI-обработке материала и необходимости проверки результата; подробности по ссылке. Не дополнительная регистрация.
- Ошибка формата показывается рядом с полем; введённые данные сохраняются.
- После отправки повторное нажатие не создаёт вторую задачу.

### P — Обработка

- Отображать реальные этапы: «Получаем материал», «Собираем рецепт», «Готов к проверке».
- Без выдуманного процента и точного срока.
- Текст: «Можно закрыть приложение — результат не потеряется» допустим только после реализации устойчивого хранения задач и восстановления после сбоя.
- При закрытии приложения задача продолжается; результат доступен на главной и в черновиках. Бот присылает одну кнопку открытия готового черновика.
- При ошибке показать, какой этап не выполнен, и действие: исправить источник, повторить временно неудавшийся запрос или добавить другой материал.
- Не отправлять повторно AI-запрос только из-за обновления экрана.

### D — Проверить рецепт

- Полный экран, заголовок «Проверьте рецепт» и отметка «Черновик».
- Название, ингредиенты, шаги, доступные время/порции, источник.
- Неизвестные количества и сомнительные сведения обозначены явно, не превращаются в нули или уверенные догадки.
- Основная кнопка «Сохранить в мои рецепты».
- Вторичная кнопка «Исправить» ведёт в редактор; возвращение не теряет черновик.
- После сохранения сообщение «Рецепт сохранён» и полный экран R; доступны «Начать готовить» и «К моим рецептам».
- Уход без сохранения оставляет черновик, но он не участвует в подборе ужина.

### E — Редактирование

- Отдельный экран с понятными группами полей, не длинная форма поверх карточки.
- Можно исправить название, ингредиенты, шаги, порции, время и заметки.
- «Применить изменения» возвращает в исходную карточку и сохраняет её статус: черновик остаётся черновиком до явного сохранения в библиотеку.
- При выходе с неприменёнными изменениями предложить остаться или выйти без этих изменений.
- Повторное AI-извлечение не перезаписывает пользовательские правки автоматически.

### L — Мои рецепты

- По умолчанию показывать сохранённые рецепты; черновики обозначить отдельно и дать к ним явный доступ.
- Поиск находится здесь же. После открытия карточки и возврата сохраняются запрос и положение списка.
- Карточка даёт достаточно информации для выбора: название, известное время, источник. Не подставлять случайное изображение как будто это фотография блюда.
- Пустая библиотека: «Здесь будут ваши рецепты» и «Сохранить первый рецепт».
- Архивирование — по подтверждению, с понятным результатом. Удаление всех данных не находится среди основных действий.

### Q — Что приготовить?

- Вопрос: «Что хочется приготовить?».
- Пример запроса: «Есть курица, нужно на ужин до 30 минут и без духовки».
- Уточнения необязательные; не заставлять проходить анкету.
- Ищем в сохранённых рецептах владельца, а не среди неподтверждённых черновиков.
- Результат — несколько вариантов с коротким объяснением соответствия запросу.
- Не обещать соответствие условию, если нужные сведения неизвестны; обозначать неопределённость.
- Нет результатов: автоматически предложить один новый AI-рецепт с ингредиентами и шагами, а также дать возможность изменить запрос.
- Предложение явно помечается как созданное AI и не входит в коллекцию до подтверждения «Добавить рецепт».
- После подтверждения рецепт получает происхождение `generated` и подпись «Создано для меня · AI»; отказ оставляет коллекцию без изменений.
- Пустая коллекция: объяснить ситуацию; пользователь может начать с поиска и добавить предложенный рецепт после просмотра.

### R — Рецепт

- Полноценная страница с «Назад», не попап.
- Ингредиенты и шаги — основное содержание. Источник, предупреждения и собственные заметки доступны без поиска в переписке.
- «Начать готовить» — главное действие; редактирование вторично.
- Кнопка «Назад» возвращает в точный контекст: подбор ужина, библиотеку или главную.

### C — Готовка

- Один крупный шаг, номер шага и общее количество.
- Ингредиенты доступны во время готовки без потери текущего шага.
- «Назад» и «Дальше», на последнем шаге «Завершить».
- Выход не означает удаление прогресса; при возврате предложить «Продолжить с шага N» или «Начать заново».
- Завершение возвращает к рецепту; можно оставить личную заметку, без обязательной оценки или анкеты.

## 5. Повторы, ошибки и сохранение состояния

| Состояние | Ответ продукта | Ограничение |
|---|---|---|
| Тот же источник уже сохранён | «Этот рецепт уже есть» → открыть карточку | Без нового AI-вызова и второй записи |
| Для источника уже есть черновик | «Вы уже добавляли этот рецепт» → продолжить проверку | Не создавать ещё один черновик |
| Источник сейчас обрабатывается | Показать существующую задачу | Не запускать параллельную копию |
| Похожий, но не идентичный материал | Показать возможное совпадение и дать выбор | Не объединять автоматически |
| Нужна отдельная версия | Явное действие «Создать копию» | Копия сохранённой карточки сама по себе не требует AI |
| Нужно повторно извлечь источник | Отдельное подтверждаемое действие | Сохранить старую версию и ручные правки до принятия нового результата |
| Источник недоступен | Объяснить причину и предложить другой материал | Не выдумывать рецепт |
| Сбой сети при сохранении | Сохранить введённое и дать повторить | Не сообщать об успехе до подтверждения сервера |
| Закрытие приложения | Восстановить черновик или задачу | Не требовать повторно присылать материал |
| Исчерпана квота AI | Объяснить ограничение и как обратиться к владельцу | Библиотека и готовка остаются доступны |

Дедупликация всегда в границах пользователя. Для YouTube используем ID видео независимо от short/watch/shorts-ссылки и tracking-параметров. Для точных повторов текста и файлов — устойчивый отпечаток. Похожие названия сами по себе не доказывают совпадение.

## 6. Основные маршруты для проверки

1. Новый пользователь: приглашение → Start → Сохранить рецепт → источник → обработка → проверить → сохранить → рецепт.
2. Возвращающийся, добавление: источник в бот → проверка дубля → обработка → уведомление → черновик в Mini App → сохранить.
3. Повтор: тот же источник → открыть существующую карточку; число рецептов и AI-вызовов не увеличилось.
4. Ужин: Что приготовить? → свободный запрос → варианты из коллекции → рецепт → готовка → завершить.
5. Знакомый рецепт: Мои рецепты → поиск → рецепт → назад; запрос и позиция списка сохранены.
6. Прерывание: начать импорт → закрыть приложение → вернуться → открыть результат без повторной обработки.
7. Редактирование: открыть сохранённый рецепт → исправить → применить → вернуться; другие поля и заметки не потерялись.

## 7. Границы следующего этапа

- Сначала дизайн главного экрана H, затем карточки R и сценария добавления A → P → D.
- Согласовать визуальное направление до переноса на остальные экраны.
- Эта схема не разрешает автоматически менять существующие рецепты или удалять дубли из текущей библиотеки.
- Надёжное восстановление задач, защита от повторов и сохранение прогресса — требования к будущей реализации, не уже подтверждённые функции.
- Планирование меню из нескольких блюд и список покупок пока не входят в утверждённую основу.
