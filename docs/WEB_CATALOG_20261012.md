# Браузерный каталог рецептов — 12 октября 2026

Запрос владельца: веб-версия, которую открывают из обычного браузера, фильтруют по кухням и другим признакам и выбирают рецепт.

## Исследование

Изучены открытые страницы 12 октября 2026:

- https://eda.rambler.ru/recepty — кухня, категория, включённые и исключённые ингредиенты, сортировка; в карточке время, порции, количество ингредиентов.
- https://www.edimdoma.ru/retsepty — категории блюд, поиск по названию, время приготовления в выдаче.
- https://www.iamcook.ru/ — тематическая навигация и пошаговые рецепты.

Использованы общие сценарии навигации; рецепты, фотографии и оформление конкурентов не копировались.

## Реализация

- `/recipes`: открытый каталог 250 собственных готовых рецептов, 24 карточки на страницу.
- Поиск, кухня/стиль, тип блюда и основа, максимальное время, продукты для включения и исключения. Продукты через запятую сочетаются по И; исключения используют существующие пищевые алиасы.
- Кухни из существующих категорий дополнены редакционными метками для идентифицируемых блюд; без определённой кухни — домашняя еда. Это домашние адаптации, не обещание аутентичности.
- Сортировка: сначала с фото, сначала быстрые, по названию. Условия сохраняются в URL; прямые ссылки, возврат в подборку и история браузера поддерживаются.
- `/recipes/:id`: ингредиенты, инструкции, расчётные КБЖУ, пересчёт 1–20 порций, отметки ингредиентов, копирование ссылки и печать. Числа внутри текста шагов остаются базовыми: это явно указано возле инструкций.
- Избранное хранится только в текущем браузере, не синхронизируется с Telegram/MAX. При недоступности localStorage сохраняется в памяти страницы с объяснением.
- Публичные API `/api/catalog` и `/api/catalog/:id` проецируют исключительно SEED_RECIPES. Частные коллекции, AI-результаты, аккаунты и подписки не читаются и не меняются; действующие API остаются защищёнными.
- Добавлены ссылки на каталог из главного лендинга. Новый экран не загружает SDK мессенджеров.
- Дизайн сохраняет бумажную, оливковую и сиреневую палитру проекта. Используются только уже выпущенные фотографии; для остальных рецептов та же карточка и единая нейтральная иллюстрация без текста. По уточнению владельца отдельные текстовые карточки исключены. На странице рецепта указано, что существующие изображения созданы ИИ.
