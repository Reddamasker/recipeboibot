# Визуальные фильтры: тест с телефона

Владелец просит протестировать выбор кухни и продуктов кнопками, как в Яндекс Еде, оставив текстовый поиск дополнительным. После локальной проверки сообщил, что ссылка не открывается с телефона: 127.0.0.1 указывает на само устройство, а не на компьютер разработчика.

Вариант включается только параметром `?filters=visual`. Обычный `/recipes` сохраняет прежний интерфейс. Кухни представлены фотоплитками, продукты — кнопками с множественным выбором, время — переключателями. Дополнительные продукты, исключения и типы блюд раскрываются по кнопке. Сброс, история браузера и возврат из рецепта сохраняют выбранный вариант интерфейса. Фотографии взяты из уже выпущенного каталога.

Сценарий фильтров подтверждён справкой Яндекс Еды: https://yandex.com/support/eda-vendor-kz/ru/account/menu. Оформление и материалы конкурента не копировались.

Локально: 589/589 тестов в отдельной копии без посторонних изменений. Браузерные проверки: desktop, 390/320 px без горизонтального переполнения документа; кухни, несколько продуктов, время, дополнительные ограничения, открытие рецепта и возврат, сохранение обычного интерфейса без параметра. Курица+рис дают четыре рецепта, до 30 минут — два.

Область выпуска: только тестовый контур для проверки владельцем с телефона. Основной сайт и MAX остаются на предыдущем выпуске. Тестовый бот сохраняет все существующие функции основной версии и получает дополнительный вариант каталога.

Публикация выполняется через `scripts/deploy-test.js --check`, затем `--apply`, с резервом данных и проверкой точного состава опубликованного кода. Фактический результат фиксируется после завершения.
