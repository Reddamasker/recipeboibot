Владелец попросил самостоятельно пройти пустая коллекция → меню → заполненные покупки и исправить оставшиеся заглушки/кнопки. Разрешён выпуск только в `@recipeboi_test_bot`, включая ранее одобренный перезапуск test. Production и MAX не публиковать.

Telegram Desktop на рабочем компьютере не установлен. Проверка использует настоящий опубликованный Mini App в Chrome с подписанной авторизацией и реальные `/api/workspace` записи; это не утверждение о проверке нативного Telegram/WebView на телефоне. Создаётся отдельный `private-test` профиль существующим штатным механизмом; исходный маршрут восстанавливается и сверяются хеши данных первоначального аккаунта. Записи проверки остаются в отдельном профиле, не сбрасывают квоту и исключаются из публичной аналитики. Второй polling не запускается.

## Найдено и исправлено

1. После удаления всех купленных продуктов источники оставались, но управление ими исчезало. Теперь источники доступны и при пустом списке, есть явное «Вернуть убранные продукты». `restoreExcluded:true` в прежних `groceries.fromRecipe/fromPlan` восстанавливает только выбранные источники с актуальными количествами. По умолчанию исключения сохраняются; ручные позиции и другие блюда не сбрасываются.
2. Перезагрузка/вперёд/назад теряли открытую карточку блюда из меню. Новые разделы восстанавливают `recipe` через существующий `openRecipe`, сохраняя ограничения доступа и поведение истории.
3. Создание подборки из конкретного рецепта не выбирало этот рецепт. Теперь он отмечен заранее; человек может изменить состав перед сохранением.
4. Поле «Найти рецепт» во вкладке подборок искало только имена подборок. Непустой запрос теперь ищет рецепты по названию, тегам и ингредиентам; внутри открытой подборки сохраняется её область поиска.
5. При ошибке следующей страницы каталога выбранный рецепт оставался, кнопка сохранения включалась, но ничего не делала. Сохранение уже выбранного рецепта теперь работает независимо от загрузки следующей страницы.
6. Подсказка быстрого добавления уводила в прежний интерфейс. Она открывает существующую рабочую форму добавления.
7. Закрытый preview первого рецепта мог предлагаться в списке для меню/покупок и затем отклоняться сервером. Такие preview и черновики теперь исключены из доступных вариантов; публичные и доступные личные рецепты остаются.
