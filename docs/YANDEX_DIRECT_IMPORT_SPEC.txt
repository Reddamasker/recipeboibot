Твои рецепты — статистика Директа
Сайт: https://dishfinder.ru
Назначение: внутренний дашборд владельца Telegram-бота, один рекламодатель spassky1997.
Импортируемая кампания: 715053149. Размещение в собственной воронке: ya-dinner-202610.

Приложение каждый час получает агрегированный отчёт сервиса Reports API v501:
CAMPAIGN_PERFORMANCE_REPORT, период ALL_TIME, фильтр CampaignId EQUALS 715053149.
Поля: CampaignId, Impressions, Clicks, Cost. IncludeVAT=YES.
Денежные значения получаются в рублях, сохраняются целым числом копеек.
Авторизация: OAuth direct:api; секретный токен хранится только в серверном .env.local.
API-запросы приложения предназначены только для чтения отчётов, управление рекламой не реализовано.
Отложенные отчёты 201/202 запрашиваются повторно с теми же параметрами и retryIn.

В дашборде под отдельным паролем показываются показы, клики Директа, расходы с НДС,
средняя стоимость клика с НДС, время и состояние последнего обновления.
Можно вручную запросить обновление. Итоговые данные заменяются атомарно, повторный импорт
не увеличивает счётчики. При ошибке сохраняются предыдущие данные, доступен статус ошибки.
Не импортируются персональные данные посетителей и данные других рекламодателей.
Охват поисковой рекламы не подменяется количеством показов.

Собственная воронка отдельно учитывает переходы по рекламной ссылке, запуск бота,
первый рецепт, начало пробного периода и подтверждённую оплату, а также A/B выдачи промокода.
Клики API Директа и зарегистрированные запросы на редирект сохраняются отдельными величинами.
Дашборд защищён серверной сессией; API импорта требует авторизации, проверяет Origin и
специальный заголовок запроса, частота ручного импорта ограничена.
Тестовый бот имеет ту же кодовую базу, но автоматический импорт реальной кампании в нём отключён.
