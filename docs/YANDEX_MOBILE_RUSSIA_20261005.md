# Россия и смартфоны — 5 октября 2026

Владелец сообщил, что прямая ссылка Telegram и служебный редирект реагируют одинаково, затем поручил акцент на мобильных и всю РФ. До изменения API подтвердил: десктоп не был исключён, во всех трёх группах кампании 715053149 стоял RegionIds=[1] («Москва и область»). Корректировок устройств не было ни в кампании, ни в группах.

Применено через официальный API Директа и подтверждено отдельным повторным get:

- RegionIds=[225] («Россия») во всех группах: 5808406440, 5808406950, 5808407833.
- На уровне кампании добавлена DESKTOP_ADJUSTMENT с коэффициентом 0 (корректировка −100%), ID 192125661637. Этот тип исключает все устройства, кроме смартфонов: компьютеры, планшеты и Smart TV. Групповых корректировок устройств, которые могли бы переопределить кампанию, нет.
- Смартфоны iOS и Android включены без повышающей корректировки.

Стратегия и состояние кампании совпали с сохранённым снимком до изменения: WB_MAXIMUM_CLICKS, поиск; РСЯ SERVING_OFF; WeeklySpendLimit=2459000000 (2459 ₽ без НДС / 2999,98 ₽ с НДС в неделю), BidCeiling=4500000 (4,50 ₽ без НДС / 5,49 ₽ с НДС), State=ON, Status=ACCEPTED. Существующая демографическая корректировка сохранена. Ссылки, объявления, тексты, ключевые фразы и A/B не изменялись. Другая кампания не затронута. Код, серверы и данные ботов не изменялись; публикация ботов для настройки Директа не требуется.

Снимки и ответы API в игнорируемом data/: direct-mobile-russia-before.json, direct-mobile-russia-device-result.json, direct-mobile-russia-region-result.json, direct-mobile-russia-after.json. После успешного add локальная проверка первоначально ожидала Id вместо документированного массива Ids; операция на стороне Директа уже прошла. Перед продолжением состояние перечитано, коэффициент 0 подтверждён, повторного add не выполнялось. Затем update регионов во всех трёх группах завершился без ошибок и финальный снимок подтвердил настройки.

Официальное описание охвата DESKTOP_ADJUSTMENT: [Корректировки](https://yandex.ru/dev/direct/doc/ru/objects/bidmodifier); [изменение регионов группы](https://yandex.ru/dev/direct/doc/ru/adgroups/update).
