## Подключение продукта

`YANDEX_DIRECT_RECIPE_FIRST_CAMPAIGN_ID` задаётся только основному боту, где уже есть доступ к API рекламы. Новый общий модуль определяет метку и ссылку; дашборд открывает новую кампанию после появления её импорта. На test/MAX новые рекламные секреты не передаются. Источник регистрируется на сайте до первого платного входа; MAX получает его из подписанной передачи выбранного рецепта.

Используются прежние события и метрики. Импорт добавляет пятую кампанию, не удваивая одинаковый внешний ID. Ценовой эксперимент сохраняет ключ, цены, распределение и прежние назначения; добавлена только новая разрешённая метка. Trial/оплаты Telegram/MAX показаны раздельно.
